> 系列：Spring Cloud Alibaba 2025 微服务实战教程

## 前言

在开始微服务开发之前，我们需要准备好开发环境。本教程使用的是 Spring Cloud Alibaba 2025 年最新版本栈，基于 Spring Boot 4.0.x 和 JDK 17。请确保你的开发环境满足以下要求。

---

## 1. JDK 17 安装与配置

### 为什么选择 JDK 17？

Spring Boot 4.0.x 底层基于 Spring Framework 7.0，要求 **JDK 17+**。JDK 17 是 Java 的 LTS（长期支持）版本，也是目前 Spring 生态的主流基线。

### 安装步骤

#### Windows

1. 访问 [Adoptium](https://adoptium.net/) 或 [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) 下载 JDK 17
2. 推荐使用 **Eclipse Temurin**（原 AdoptOpenJDK），开源免费
3. 安装时勾选"添加到 PATH"

#### macOS

```bash
# 使用 Homebrew 安装
brew install openjdk@17

# 配置环境变量（添加到 ~/.zshrc）
export JAVA_HOME="/opt/homebrew/opt/openjdk@17"
export PATH="$JAVA_HOME/bin:$PATH"
```

#### Linux

```bash
# Ubuntu/Debian
sudo apt install openjdk-17-jdk

# CentOS/RHEL
sudo yum install java-17-openjdk-devel
```

### 验证安装

```bash
java -version
# 输出示例：
# openjdk version "17.0.9" 2023-10-17
# OpenJDK Runtime Environment Temurin-17.0.9+9 (build 17.0.9+9)
# OpenJDK 64-Bit Server VM Temurin-17.0.9+9 (build 17.0.9+9, mixed mode)

echo $JAVA_HOME
# /path/to/jdk-17
```

## 2. Maven 安装与配置

### 安装

本项目使用 Maven 作为构建工具，版本要求 3.8+。

#### Windows

1. 访问 [Maven 官网](https://maven.apache.org/download.cgi) 下载 Binary zip
2. 解压到 `C:\Program Files\apache-maven-3.9.x`
3. 配置环境变量 `MAVEN_HOME` 和 `PATH`

#### macOS / Linux

```bash
# macOS
brew install maven

# Linux
sudo apt install maven
```

### 配置 settings.xml

编辑 `~/.m2/settings.xml`（没有则创建），配置阿里云镜像加速：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings>
    <mirrors>
        <mirror>
            <id>aliyun</id>
            <name>Aliyun Maven Mirror</name>
            <url>https://maven.aliyun.com/repository/public</url>
            <mirrorOf>central</mirrorOf>
        </mirror>
    </mirrors>
</settings>
```

### 验证

```bash
mvn -version
# Apache Maven 3.9.x
# Java version: 17.0.x
```

## 3. Docker Desktop 安装

### 为什么需要 Docker？

本教程依赖以下基础设施：

| 组件 | 用途 | 端口 |
|------|------|------|
| Nacos | 服务注册 + 配置中心 | 8848 / 9848 |
| MySQL | 关系型数据库 | 3306 |
| Consul | 备用注册中心 | 8500 |
| SkyWalking | 链路追踪 | 11800 / 12800 |

使用 Docker 可以一键启动所有基础设施，无需逐个安装配置。

### 安装 Docker Desktop

#### Windows

1. 访问 [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop/)
2. 下载并安装，需要启用 WSL 2
3. 重启后运行 Docker Desktop

#### macOS

```bash
brew install --cask docker
```

#### Linux

```bash
# Ubuntu
sudo apt install docker.io docker-compose-v2
sudo usermod -aG docker $USER  # 免 sudo 运行
```

### 验证

```bash
docker --version
# Docker version 24.x.x

docker compose version
# Docker Compose version v2.x.x
```

## 4. IDE 选择与配置

推荐使用 **IntelliJ IDEA**（Community 版免费）或 **VS Code** + Spring Boot 插件。

### IntelliJ IDEA 配置要点

1. **Lombok 插件**：`Settings → Plugins → 搜索 Lombok → Install`
2. **启用注解处理器**：`Settings → Build → Compiler → Annotation Processors → Enable`
3. **Maven 配置**：`Settings → Build → Maven → 选择本地 Maven 安装`

### VS Code 推荐插件

- Extension Pack for Java
- Spring Boot Extension Pack
- Lombok Annotations Support

## 常见问题

### Q: 可以不用 Docker 吗？

可以，但需要手动安装 Nacos、MySQL 等中间件。强烈建议使用 Docker，本教程后续的 `docker-compose.yml` 可以直接复用。

### Q: JDK 21 可以吗？

可以。Spring Boot 4.0.x 要求 JDK 17+，JDK 21 完全兼容。

### Q: 国内网络下载 Docker 镜像慢怎么办？

```json
// Docker Desktop Settings → Docker Engine → 添加镜像加速器
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://docker.xuanyuan.me"
  ]
}
```
