# 10. 微服务文件上传 —— Feign 跨服务传输

> 系列：Spring Cloud Alibaba 2025 微服务实战教程

> 前置：完成 [04. 用户 CRUD 服务提供者](./04.第一个服务提供者-用户CRUD.md) 和 [05. Feign 服务消费者](./05.服务消费者-Feign声明式调用.md)

---

## 前言

文件上传是 Web 开发中最常见的功能之一。但在微服务架构中，文件需要跨服务传输——客户端上传到消费者，消费者再通过 Feign 转发给提供者。

本章涉及两个模块：
- **provider-file**：文件上传服务提供者（接收并存储文件，同时具备用户 CRUD）
- **consumer-feign-file**：通过 Feign 转发文件上传请求

---

## 1. 架构设计

```
浏览器
  │ POST /feign/upload (MultipartFile)
  ▼
consumer-feign-file :8083
  │ Feign + SpringFormEncoder
  ▼
provider-file :9001
  │ 保存文件到磁盘
  ▼
  D:/upload/xxx.jpg
```

**为什么需要中间层？**
- 安全：前端不直接访问文件存储服务
- 权限校验：在消费者层做认证鉴权
- 业务编排：上传文件 + 更新数据库可以作为一个事务

### 2.4 文件上传 Controller

```java
package cn.cicoding.provider.file.controller;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

import java.io.File;
import java.io.IOException;
import java.util.UUID;

@RestController
@RequestMapping("/user")
public class UserController {

    @Value("${file.upload-dir:D:/}")
    private String uploadDir;

    // ... 用户 CRUD 接口省略（与 04 章相同） ...

    @PostMapping("/upload")
    public String upload(@RequestPart("file") MultipartFile file) {
        if (file.isEmpty()) {
            return "文件为空";
        }

        // 生成唯一文件名
        String originalFilename = file.getOriginalFilename();
        String suffix = originalFilename != null
                ? originalFilename.substring(originalFilename.lastIndexOf("."))
                : "";
        String newFilename = UUID.randomUUID().toString() + suffix;

        // 保存到配置的目录
        File dest = new File(uploadDir + newFilename);
        try {
            file.transferTo(dest);
            return "上传成功: " + dest.getAbsolutePath();
        } catch (IOException e) {
            return "上传失败: " + e.getMessage();
        }
    }
}
```

### 3.4 核心代码：Feign 文件上传配置

```java
package cn.cicoding.consumer.file.feign;

import feign.form.spring.SpringFormEncoder;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class MultipartSupportConfig {

    @Bean
    public feign.codec.Encoder feignFormEncoder() {
        // ★ 替换默认编码器，支持 multipart/form-data
        return new SpringFormEncoder();
    }
}
```

### 3.5 Feign 接口

```java
package cn.cicoding.consumer.file.feign;

import feign.Headers;
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.multipart.MultipartFile;

import static org.springframework.http.MediaType.MULTIPART_FORM_DATA_VALUE;

@FeignClient(
    name = "spring-cloud-alibaba-provider-file",
    configuration = MultipartSupportConfig.class  // ★ 使用自定义编码器
)
public interface UserFeignClient {

    @PostMapping(value = "/user/upload", consumes = MULTIPART_FORM_DATA_VALUE)
    @Headers("Content-Type: multipart/form-data")
    String handleFileUpload(@RequestPart("file") MultipartFile file);
}
```

**关键注解**：
- `@RequestPart("file")`：**必须用 `@RequestPart` 而非 `@RequestParam`**，这是文件跨服务传输的关键
- `consumes = MULTIPART_FORM_DATA_VALUE`：声明 Content-Type
- `configuration = MultipartSupportConfig.class`：指定 Feign 配置类

### 3.6 Controller

```java
package cn.cicoding.consumer.file.controller;

import cn.cicoding.consumer.file.feign.UserFeignClient;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

@RestController
@RequestMapping("/feign")
public class FeignFileController {

    @Autowired
    private UserFeignClient userFeignClient;

    @PostMapping("/upload")
    public String uploadFile(@RequestParam("file") MultipartFile file) {
        // 接收前端上传的文件，通过 Feign 转发给 provider
        return userFeignClient.handleFileUpload(file);
    }
}
```

> **注意**：前端请求用 `@RequestParam`（传统表单上传），Feign 转发用 `@RequestPart`（跨服务 multipart）。

## 4. 启动与测试

### 启动顺序

```bash

mvn spring-boot:run -pl spring-cloud-alibaba-provider-file

# 2. consumer-feign-file（端口 8083）
```

```bash

curl -F "file=@/path/to/test.jpg" http://localhost:8083/feign/upload

# 返回: 上传成功: D:/a1b2c3d4-....jpg
```

### 调用链路

```
curl -F "file=@test.jpg" localhost:8083/feign/upload
    │
    ▼  @RequestParam("file")
FeignFileController.uploadFile()
    │  userFeignClient.handleFileUpload(file)
    ▼  @RequestPart("file") + SpringFormEncoder
UserFeignClient → HTTP multipart 请求 → provider-file:9001
    │
    ▼  @RequestPart("file")
UserController.upload()
    │  file.transferTo(dest)
    ▼
  D:/xxx-xxx.jpg
```

## 5. 核心知识点总结

| 要点 | 说明 |
|------|------|
| `feign-form-spring` | Feign 文件上传必需的编码器库 |
| `SpringFormEncoder` | 替换 Feign 默认编码器，支持 `MultipartFile` |
| `@RequestPart` vs `@RequestParam` | 前端传文件用 `@RequestParam`，Feign 转发用 `@RequestPart` |
| `consumes = MULTIPART_FORM_DATA_VALUE` | 明确告诉 Feign 这是 multipart 请求 |
| `spring.servlet.multipart` | 限制上传文件大小，防止恶意上传撑爆磁盘 |

## 常见问题

### Q: Feign 报 `No qualifying bean of type 'feign.codec.Encoder'`？

检查 `MultipartSupportConfig` 是否正确配置了 `SpringFormEncoder` Bean。

### Q: 大文件上传失败？

1. 检查 `spring.servlet.multipart.max-file-size` 是否足够
2. 检查 Nginx/网关的反向代理超时和 body 大小限制
3. 考虑使用分片上传方案
