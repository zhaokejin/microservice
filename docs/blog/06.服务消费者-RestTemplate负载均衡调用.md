# 06. 服务消费者 —— RestTemplate 负载均衡调用

## 前言

上一章学习了 Feign 声明式调用，但有时你需要更底层的控制。本章学习另一种服务调用方式——**RestTemplate + LoadBalancer**。它比 Feign 更灵活，适合需要精细控制请求的场景。

---

## 1. Feign vs RestTemplate

| 对比维度 | Feign | RestTemplate |
|---------|-------|-------------|
| 编码方式 | 声明式（接口+注解） | 编程式（代码拼接） |
| 代码量 | 少 | 较多 |
| 灵活性 | 受注解限制 | 完全自定义 |
| 请求控制 | 框架处理 | 手动控制 |
| 适用场景 | 标准 REST 调用 | 自定义请求、文件上传等 |
| 推荐度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

> **建议**：优先使用 Feign，只在 Feign 无法满足需求时（如需要自定义 Header、特殊 Content-Type）使用 RestTemplate。

---

## 2. 模块概览

| 项目 | 值 |
|------|-----|
| 模块名 | `spring-cloud-alibaba-consumer-ribbon` |
| 端口 | 8081 |
| 服务名 | `spring-cloud-alibaba-consumer-ribbon` |
| 依赖服务 | `spring-cloud-alibaba-provider`（端口 9000） |

> 模块名中的 "ribbon" 仅作历史标识。实际上本项目使用的是 Spring Cloud LoadBalancer。

## 3. pom.xml

```xml
<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    <!-- Nacos 服务注册发现 -->
    <dependency>
        <groupId>com.alibaba.cloud</groupId>
        <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
    </dependency>
    <!-- LoadBalancer 负载均衡 -->
    <dependency>
        <groupId>org.springframework.cloud</groupId>
        <artifactId>spring-cloud-starter-loadbalancer</artifactId>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-actuator</artifactId>
    </dependency>
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <optional>true</optional>
    </dependency>
</dependencies>
```

与 Feign 模块的区别：
- ❌ 不需要 `spring-cloud-starter-openfeign`
- ✅ 保留 `spring-cloud-starter-loadbalancer`（通过服务名调用时做负载均衡）

## 5. 代码实现

### 5.1 启动类

```java
package cn.cicoding;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class SpringCloudAlibabaConsumerRibbonApplication {

    public static void main(String[] args) {
        SpringApplication.run(SpringCloudAlibabaConsumerRibbonApplication.class, args);
    }
}
```

> SCA 2025 自动注册服务到 Nacos，无需 `@EnableDiscoveryClient`。

### 5.2 RestTemplate 配置

在启动类中添加 `RestTemplate` Bean：

```java
@SpringBootApplication
public class SpringCloudAlibabaConsumerRibbonApplication {

    public static void main(String[] args) {
        SpringApplication.run(SpringCloudAlibabaConsumerRibbonApplication.class, args);
    }

    @Bean
    @LoadBalanced
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}
```

**`@LoadBalanced` 注解的作用**：
1. 拦截 RestTemplate 的所有请求
2. 从 URL 中提取服务名（如 `spring-cloud-alibaba-provider`）
3. 从 Nacos 获取该服务的实例列表
4. 负载均衡选择一个实例，将服务名替换为真实 IP:端口

### 5.3 实体类

```java
package cn.cicoding.entity;

import lombok.Data;

@Data
public class User {
    private Integer id;
    private String userName;
    private String password;
    private String phone;
}
```

### 5.4 Controller（核心）

```java
package cn.cicoding.controller;

import cn.cicoding.entity.User;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.client.RestTemplate;

@RequestMapping("/ribbon")
@RestController
public class RestTemplateController {

    @Autowired
    private RestTemplate restTemplate;

    @GetMapping("/user/{id}")
    public User findById(@PathVariable Long id) {
        // ★ URL 中使用服务名，LoadBalancer 自动解析为真实地址
        return restTemplate.getForObject(
                "http://spring-cloud-alibaba-provider/user/{id}",
                User.class,
                id);
    }
}
```

### 调用原理图解

```
1. 浏览器请求 → /ribbon/user/1
                     ↓
2. RestTemplate.getForObject("http://spring-cloud-alibaba-provider/user/1")
                     ↓
3. @LoadBalanced 拦截器 → 查询 Nacos
   Nacos 返回：["192.168.1.100:9000", "192.168.1.101:9000"]
                     ↓
4. LoadBalancer 轮询选择 → "192.168.1.100:9000"
                     ↓
5. 实际请求：http://192.168.1.100:9000/user/1
                     ↓
6. 返回 User 对象
```

## 7. 其他 RestTemplate 调用方式

```java
// GET 获取列表
List<User> users = restTemplate.exchange(
    "http://spring-cloud-alibaba-provider/user",
    HttpMethod.GET,
    null,
    new ParameterizedTypeReference<List<User>>() {}).getBody();

// POST 添加数据
HttpHeaders headers = new HttpHeaders();
headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);
MultiValueMap<String, String> body = new LinkedMultiValueMap<>();
body.add("userName", "test");
body.add("password", "123");
HttpEntity<MultiValueMap<String, String>> request = new HttpEntity<>(body, headers);
String result = restTemplate.postForObject(
    "http://spring-cloud-alibaba-provider/user", request, String.class);

// PUT 更新
restTemplate.put("http://spring-cloud-alibaba-provider/user?userId=1&userName=new", null);

// DELETE 删除
restTemplate.delete("http://spring-cloud-alibaba-provider/user?userId=1");
```

## 8. Feign vs RestTemplate：何时用哪个？

| 场景 | 推荐 |
|------|------|
| 标准 CRUD 接口调用 | Feign |
| 需要自定义 Header/Cookie | RestTemplate |
| 文件上传下载 | Feign (配合 feign-form) |
| 第三方 HTTP API 调用 | RestTemplate |
| 批量请求聚合 | Feign |

## 常见问题

### Q: `@LoadBalanced` 和不加有什么区别？

```java
// 不加 @LoadBalanced：URL 必须是真实 IP:端口
restTemplate.getForObject("http://192.168.1.100:9000/user/1", User.class);

// 加 @LoadBalanced：URL 可以用服务名，自动负载均衡
restTemplate.getForObject("http://spring-cloud-alibaba-provider/user/1", User.class);
```

### Q: 为什么模块名叫 ribbon？

Netflix Ribbon 曾是 Spring Cloud 的默认负载均衡器，但已于 2021 年进入维护模式。Spring Cloud 2024.0+ 全面用 LoadBalancer 替代。模块名保留 "ribbon" 仅作历史习惯。
