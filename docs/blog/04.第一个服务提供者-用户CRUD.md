# 04. 第一个服务提供者 —— 用户 CRUD

> 系列：Spring Cloud Alibaba 2025 微服务实战教程
>
> 前置：完成 [03. Maven 多模块父工程创建](./03.Maven多模块父工程创建.md)

## 前言

本章创建第一个微服务模块——**用户管理服务提供者**。这是一个完整的 CRUD 服务，集成 MyBatis + MySQL，并注册到 Nacos。从这里开始，你将亲手体验微服务从零到一的全过程。

---

## 1. 模块概览

| 项目 | 值 |
|------|-----|
| 模块名 | `spring-cloud-alibaba-provider` |
| 端口 | 9000 |
| 服务名（Nacos） | `spring-cloud-alibaba-provider` |
| 数据库 | MySQL（mytest 库，t_user 表） |
| ORM | MyBatis 4.0.1 + MyBatis-Spring 4.0.0 |

### 技术栈

```
spring-boot-starter-web          # REST API
spring-cloud-starter-alibaba-nacos-discovery  # Nacos 服务注册
mybatis-spring-boot-starter      # MyBatis ORM
mysql-connector-j                # MySQL 驱动
lombok                           # 简化代码
spring-boot-starter-actuator     # 健康检查端点
```

## 2. 创建子模块 pom.xml

在 `spring-cloud-alibaba-provider/pom.xml`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
         http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <!-- 继承父 POM -->
    <parent>
        <groupId>cn.cicoding</groupId>
        <artifactId>microservice</artifactId>
        <version>1.0.0</version>
    </parent>

    <artifactId>spring-cloud-alibaba-provider</artifactId>
    <name>spring-cloud-alibaba-provider</name>
    <description>服务提供者 —— 用户 CRUD + MyBatis + MySQL + Nacos 注册</description>

    <dependencies>
        <!-- Web -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <!-- Nacos 服务注册发现 -->
        <dependency>
            <groupId>com.alibaba.cloud</groupId>
            <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
        </dependency>

        <!-- MyBatis -->
        <dependency>
            <groupId>org.mybatis</groupId>
            <artifactId>mybatis-spring</artifactId>
            <version>4.0.0</version>
        </dependency>
        <dependency>
            <groupId>org.mybatis.spring.boot</groupId>
            <artifactId>mybatis-spring-boot-starter</artifactId>
            <version>4.0.1</version>
        </dependency>

        <!-- MySQL 驱动 -->
        <dependency>
            <groupId>com.mysql</groupId>
            <artifactId>mysql-connector-j</artifactId>
            <scope>runtime</scope>
        </dependency>

        <!-- Actuator（健康检查） -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-actuator</artifactId>
        </dependency>

        <!-- Lombok -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <optional>true</optional>
        </dependency>

        <!-- 测试 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
</project>
```

> **注意**：`mysql-connector-j` 而非旧版的 `mysql-connector-java`。这是 MySQL Connector/J 8.0.31+ 的 artifact 改名。

## 3. 配置文件 application.yml

`src/main/resources/application.yml`：

```yaml
server:
  port: 9000

spring:
  application:
    name: spring-cloud-alibaba-provider   # Nacos 服务名
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/mytest?useSSL=false&useUnicode=true&characterEncoding=utf-8&allowMultiQueries=true&allowPublicKeyRetrieval=true&serverTimezone=UTC&autoReconnect=true
    username: root
    password: root
    hikari:
      auto-commit: true
      maximum-pool-size: 100
      max-lifetime: 1800000
      minimum-idle: 5
      idle-timeout: 300000
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
        username: nacos
        password: nacos

mybatis:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: cn.cicoding.model

logging:
  level:
    root: info
    cn.cicoding: debug

management:
  endpoints:
    web:
      exposure:
        include: '*'
  endpoint:
    health:
      show-details: always
```

### 配置要点

| 配置项 | 说明 |
|--------|------|
| `spring.application.name` | **核心配置**，同时作为 Nacos 注册的服务名 |
| `spring.cloud.nacos.discovery.server-addr` | Nacos 地址，开发环境连本地 Docker |
| `management.endpoints.web.exposure.include: '*'` | 暴露所有 Actuator 端点，后续 SBA 监控需要 |
| `allowPublicKeyRetrieval=true` | MySQL 8.0 连接必需参数 |

## 4. 代码实现

### 4.1 包结构

```

│   └── impl/
│       └── UserServiceImpl.java                 # 服务实现
└── controller/
```

### 4.2 启动类

```java

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class SpringCloudAlibabaProviderApplication {

        SpringApplication.run(SpringCloudAlibabaProviderApplication.class, args);

```

> SCA 2025 中，`spring-cloud-starter-alibaba-nacos-discovery` **自动开启**服务注册，无需额外注解。

### 4.3 实体类

```java
package cn.cicoding.model;

import lombok.Data;

@Data
public class UserDomain {
    private Integer id;
    private String userName;
    private String password;
    private String phone;
}
```

### 4.4 Mapper 接口

```java
package cn.cicoding.dao;

import cn.cicoding.model.UserDomain;
import org.apache.ibatis.annotations.*;

import java.util.List;

@Mapper
public interface UserDao {

    @Insert("INSERT INTO t_user(user_name, password, phone) VALUES(#{userName}, #{password}, #{phone})")
    int insert(UserDomain user);

    @Select("SELECT * FROM t_user")
    List<UserDomain> selectUsers();

    @Select("SELECT * FROM t_user WHERE id = #{id}")
    UserDomain findById(Integer id);

    @Update("UPDATE t_user SET user_name=#{userName}, password=#{password}, phone=#{phone} WHERE id=#{id}")
    int updateUser(UserDomain user);

    @Delete("DELETE FROM t_user WHERE id = #{id}")
    int deleteUserById(Integer id);
}
```

### 4.5 Controller

```java
package cn.cicoding.controller;

import cn.cicoding.model.UserDomain;
import cn.cicoding.service.UserService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/user")
public class UserController {

    @Autowired
    private UserService userService;

    @PostMapping
    public ResponseEntity<String> addUser(@RequestParam String userName,
                                          @RequestParam String password,
                                          @RequestParam(required = false) String phone) {
        UserDomain user = new UserDomain();
        user.setUserName(userName);
        user.setPassword(password);
        user.setPhone(phone);
        userService.insert(user);
        return ResponseEntity.ok("添加成功");
    }

    @DeleteMapping
    public ResponseEntity<String> deleteUser(@RequestParam Integer userId) {
        userService.deleteUserById(userId);
        return ResponseEntity.ok("删除成功");
    }

    @PutMapping
    public ResponseEntity<String> updateUser(@RequestParam Integer userId,
                                             @RequestParam(required = false) String userName,
                                             @RequestParam(required = false) String password,
                                             @RequestParam(required = false) String phone) {
        UserDomain user = new UserDomain();
        user.setId(userId);
        user.setUserName(userName);
        user.setPassword(password);
        user.setPhone(phone);
        userService.updateUser(user);
        return ResponseEntity.ok("更新成功");
    }

    @GetMapping
    public ResponseEntity<Object> getUsers() {
        return ResponseEntity.ok(userService.selectUsers());
    }

    @GetMapping("/{id}")
    public UserDomain findById(@PathVariable Integer id) {
        return userService.findById(id);
    }
}
```

## 常见问题

### Q: 启动报 `CommunicationsException: Communications link failure`？

MySQL 连接失败。检查：
1. Docker MySQL 是否运行：`docker compose ps`
2. 数据库 `mytest` 和表 `t_user` 是否已创建

### Q: 启动后 Nacos 看不到服务？

1. 确认 `application.yml` 中 `server-addr` 正确
2. 确认 Docker 中 Nacos 9848 端口已暴露（**SCA 2025 必须**）
3. 查看启动日志是否有 `nacos registry` 字样
