## 前言

微服务架构离不开基础设施支撑。本章使用 Docker Compose 一键启动本教程所需的全部中间件：**Nacos（服务注册与配置中心）**和 **MySQL（数据库）**。

---

## 1. 基础设施概览

| 组件 | 镜像 | 版本 | 端口 | 用途 |
|------|------|------|------|------|
| Nacos | `nacos/nacos-server` | v2.5.0 | 8848, 9848, 9849 | 服务注册发现 + 配置中心 |
| MySQL | `mysql` | 8.0 | 3306 | 关系型数据库 |

> Consul 和 SkyWalking 将在后续章节引入，本章只启动核心依赖。

---

## 2. docker-compose.yml 编写

在项目根目录创建 `docker-compose.yml`：

```yaml
services:
  # ==================== Nacos 注册与配置中心 ====================
  nacos:
    image: nacos/nacos-server:v2.5.0
    container_name: nacos-standalone
    restart: unless-stopped
    environment:
      - MODE=standalone                      # 单机模式
      - NACOS_AUTH_ENABLE=false              # 关闭认证（开发环境）
      - JVM_XMS=256m
      - JVM_XMX=256m
      - JVM_XMN=128m
    ports:
      - "8848:8848"   # HTTP 控制台
      - "9848:9848"   # gRPC 客户端通信（SCA 2025 Nacos Client 3.x 需要）
      - "9849:9849"   # gRPC 服务端通信
    volumes:
      - nacos-data:/home/nacos/data
      - nacos-logs:/home/nacos/logs

  # ==================== MySQL 数据库 ====================
  mysql:
    image: mysql:8.0
    container_name: mysql-standalone
    restart: unless-stopped
    environment:
      - MYSQL_ROOT_PASSWORD=root
      - MYSQL_DATABASE=mytest
    ports:
      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 10

volumes:
  nacos-data:
  nacos-logs:
  mysql-data:
```

### 关键配置说明

| 配置项 | 说明 |
|--------|------|
| `MODE=standalone` | Nacos 单机模式，生产环境应改为 `cluster` |
| `NACOS_AUTH_ENABLE=false` | 开发环境关闭认证，避免配置复杂度 |
| `9848:9848` | **重要**：SCA 2025 使用 Nacos Client 3.x，底层通过 gRPC 通信，**必须暴露 9848 端口**，否则注册发现失败 |
| `MYSQL_DATABASE=mytest` | 自动创建数据库，后续服务提供者直接使用 |
| `healthcheck` | MySQL 健康检查，确保依赖服务启动时数据库已就绪 |

## 3. 启动基础设施

```bash
# 在 docker-compose.yml 所在目录执行
docker compose up -d
```

首次启动会拉取镜像，可能需要几分钟。

```bash
# 查看启动状态
docker compose ps

# 查看 Nacos 日志
docker compose logs nacos

# 查看 MySQL 日志
docker compose logs mysql
```

## 4. 验证

### 4.1 验证 Nacos

浏览器访问：**http://localhost:8848/nacos**

- 由于 `NACOS_AUTH_ENABLE=false`，无需登录直接进入管理页面
- 此时服务列表为空（还没有微服务注册），这是正常的

### 4.2 验证 MySQL

```bash
# 命令行连接
docker exec -it mysql-standalone mysql -uroot -proot

# 进入后查看数据库
mysql> SHOW DATABASES;
# 应该能看到 mytest 数据库
```

或用 **MySQL Workbench** 连接 `localhost:3306`，用户名 `root`，密码 `root`。

---

## 5. 常用命令

```bash
# 停止所有服务
docker compose stop

# 重新启动
docker compose start

# 停止并删除容器（数据卷保留）
docker compose down

# 停止并删除容器+数据卷（清空所有数据）
docker compose down -v

# 查看实时日志
docker compose logs -f
```

## 常见问题

### Q: 端口冲突怎么办？

```bash
# 检查端口占用（Windows PowerShell）
netstat -ano | findstr :8848

# 修改 docker-compose.yml 中对应的 host 端口
# 例如：- "18848:8848" 将宿主机端口改为 18848
```

### Q: Nacos 启动后无法访问？

1. 检查 Docker 是否正常运行：`docker ps`
2. 查看 Nacos 日志：`docker compose logs nacos`
3. Nacos 启动较慢（JVM 初始化），等待 30-60 秒后重试

### Q: MySQL 连接被拒绝？

1. 确认 MySQL 容器健康检查通过：`docker compose ps` 看 STATUS 是否为 `healthy`
2. 如果安装了本地 MySQL，可能端口冲突，先停止本地 MySQL 服务

### Q: 为什么 Nacos 需要暴露 3 个端口？

Nacos 2.x+ 架构中：
- **8848**：HTTP 控制台 + 旧版 HTTP API
- **9848**：gRPC 客户端请求端口（**SCA 2025 Nacos Client 3.x 必须**）
- **9849**：gRPC 服务间通信端口

如果只暴露 8848，服务注册和配置拉取会失败。
