## 前言

上一章我们创建了用户管理服务，但它是一个孤立的服务。微服务架构中，服务之间需要互相调用。本章学习**最优雅的服务间调用方式——Feign 声明式调用**。

---

## 1. Feign 是什么？

**OpenFeign** 是 Spring Cloud 的声明式 HTTP 客户端。你只需定义一个接口并标注注解，Feign 自动生成实现类，完成 HTTP 请求的构造、发送、结果解析。

对比传统方式：

```java
// ❌ 传统 RestTemplate 方式：需要手动拼接 URL、处理响应
User user = restTemplate.getForObject(
    "http://service-name/user/" + id, User.class);

// ✅ Feign 方式：像调用本地方法一样调用远程服务
@FeignClient(name = "service-name")
interface UserClient {
    @GetMapping("/user/{id}")
    User findById(@PathVariable Long id);
}
```

## 3. pom.xml

```xml
<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    <!-- Nacos 服务注册发现 -->
    <dependency>
        <groupId>com.alibaba.cloud</groupId>
        <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
    </dependency>
    <!-- Feign 声明式调用 -->
    <dependency>
        <groupId>org.springframework.cloud</groupId>
        <artifactId>spring-cloud-starter-openfeign</artifactId>
    </dependency>
    <!-- LoadBalancer 负载均衡 -->
    <dependency>
        <groupId>org.springframework.cloud</groupId>
        <artifactId>spring-cloud-starter-loadbalancer</artifactId>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-actuator</artifactId>
    </dependency>
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <optional>true</optional>
    </dependency>
</dependencies>
```

**关键依赖说明**：

| 依赖 | 作用 |
|------|------|
| `spring-cloud-starter-openfeign` | Feign 核心，提供 `@FeignClient`、`@EnableFeignClients` |
| `spring-cloud-starter-loadbalancer` | **客户端负载均衡**，Feign 通过服务名调用时自动从 Nacos 获取实例列表并负载均衡选择 |

> **旧版注意**：Spring Cloud 2024.0+ 中 Ribbon 已停止维护，统一使用 Spring Cloud LoadBalancer。

## 5. 代码实现

### 5.1 启动类

```java
package cn.cicoding;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.openfeign.EnableFeignClients;

@SpringBootApplication
@EnableFeignClients   // ★ 启用 Feign
public class SpringCloudAlibabaConsumerFeignApplication {

    public static void main(String[] args) {
        SpringApplication.run(SpringCloudAlibabaConsumerFeignApplication.class, args);
    }
}
```

### 5.2 实体类（与 provider 保持一致）

```java
package cn.cicoding.user.entity;

import lombok.Data;

@Data
public class User {
    private Integer id;
    private String userName;
    private String password;
    private String phone;
}
```

### 5.3 Feign 接口（核心代码）

```java
package cn.cicoding.user.feign;

import cn.cicoding.user.entity.User;
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;

@FeignClient(name = "spring-cloud-alibaba-provider")
public interface UserFeignClient {

    @GetMapping("/user/{id}")
    User findById(@PathVariable("id") Integer id);
}
```

**`@FeignClient(name = "...")` 工作原理**：
1. `name` 指定目标服务在 Nacos 中的注册名
2. Feign + LoadBalancer 从 Nacos 获取该服务的实例列表
3. 负载均衡选择一个实例，构造 HTTP 请求
4. 将响应的 JSON 反序列化为 `User` 对象

### 5.4 Controller

```java
package cn.cicoding.user.controller;

import cn.cicoding.user.entity.User;
import cn.cicoding.user.feign.UserFeignClient;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

@RequestMapping("/feign")
@RestController
public class FeginController {

    @Autowired
    private UserFeignClient userFeignClient;

    @GetMapping("/user/{id}")
    public User findById(@PathVariable Integer id) {
        return userFeignClient.findById(id);
    }
}
```

## 7. Feign 进阶知识

### 7.1 为什么还需要 LoadBalancer？

Feign 本身只是 HTTP 客户端，不负责服务发现。当你写 `name = "spring-cloud-alibaba-provider"` 时：
1. LoadBalancer 从 Nacos 拿到 `spring-cloud-alibaba-provider` 的所有可用实例（IP:端口）
2. 负载均衡选择一个实例
3. Feign 向选中的实例发请求

如果 provider 有多个实例（如 9000 和 9001），LoadBalancer 会自动轮询分发请求。

### 7.2 Feign 常用配置

```yaml
spring:
  cloud:
    openfeign:
      client:
        config:
          default:
            connectTimeout: 5000   # 连接超时
            readTimeout: 5000      # 读取超时
            loggerLevel: basic     # 日志级别
```

### 7.3 Feign 日志

```yaml
logging:
  level:
    cn.cicoding.user.feign: DEBUG   # 打印 Feign 请求日志
```

## 常见问题

### Q: 启动报 `Load balancer does not contain an instance for the service`？

provider 没有启动或没有注册到 Nacos。确保 provider 先启动且能在 Nacos 控制台看到。

### Q: 返回 404？

检查 Feign 接口的 `@GetMapping` 路径是否与 provider Controller 的路径一致。
