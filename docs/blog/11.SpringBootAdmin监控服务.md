## 前言

随着微服务数量增多，运维监控变得至关重要。**Spring Boot Admin（SBA）** 是一款开源的微服务监控工具，提供可视化的管理界面，实时查看所有服务的运行状态、内存使用、日志等。

---

## 1. Spring Boot Admin 是什么？

SBA 是一个社区项目（`de.codecentric`），它通过读取各服务的 `/actuator` 端点来收集信息，提供：

- 📊 **服务健康状态**：UP/DOWN/UNKNOWN 一目了然
- 📈 **实时指标**：内存、线程、GC、HTTP 请求统计
- 📝 **日志查看**：在线查看各服务日志
- 🔧 **环境变量**：查看各服务的配置信息
- 📦 **JVM 信息**：堆内存、线程转储

### SBA 架构

```
        ┌─────────────────────────────┐
        │  Spring Boot Admin Server   │
        │      (端口 8000)             │
        │  @EnableAdminServer         │
        └───┬─────────┬─────────┬─────┘
            │ HTTP    │ HTTP    │ HTTP
            ▼         ▼         ▼
    ┌──────────┐ ┌──────────┐ ┌──────────┐
    │ Provider │ │ Consumer │ │ Gateway  │
    │  :9000   │ │  :8082  │ │  :7000   │
    │ /actuator│ │ /actuator│ │ /actuator│
    └──────────┘ └──────────┘ └──────────┘
            ▲         ▲         ▲
            └─────────┴─────────┘
              注册到 Nacos，SBA 自动发现
```

SBA 服务端注册到 Nacos 后，**自动发现**所有注册的服务实例，通过 HTTP 访问各服务的 `/actuator/health` 来获取状态。

## 3. pom.xml

```xml
<properties>
    <spring-boot-admin.version>4.0.4</spring-boot-admin.version>
</properties>

<dependencies>
    <!-- SBA 服务端 -->
    <dependency>
        <groupId>de.codecentric</groupId>
        <artifactId>spring-boot-admin-starter-server</artifactId>
        <version>${spring-boot-admin.version}</version>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    <!-- Nacos 服务发现（SBA 通过 Nacos 自动发现服务） -->
    <dependency>
        <groupId>com.alibaba.cloud</groupId>
        <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
    </dependency>
    <!-- Spring Security（保护 SBA 控制台） -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-security</artifactId>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-actuator</artifactId>
    </dependency>
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <optional>true</optional>
    </dependency>
</dependencies>
```

**关键点**：
- SBA 服务端**不需要** `spring-boot-admin-starter-client`，它自己就是服务端
- 需要 `spring-boot-starter-security` 保护管理界面
- 需要 `nacos-discovery` 自动发现被监控服务

## 4. 配置 application.yml

```yaml
server:
  port: 8000

spring:
  application:
    name: spring-boot-admin-server
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
        username: nacos
        password: nacos
  security:
    user:
      name: admin
      password: admin

management:
  endpoints:
    web:
      exposure:
        include: '*'
  endpoint:
    health:
      show-details: always
```

## 5. 代码实现

### 5.1 启动类

```java
package cn.cicoding.admin;

import de.codecentric.boot.admin.server.config.EnableAdminServer;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.client.discovery.EnableDiscoveryClient;

@SpringBootApplication
@EnableAdminServer        // ★ 启用 SBA 服务端
@EnableDiscoveryClient    // 启用服务发现
public class SpringBootAdminServerApplication {

    public static void main(String[] args) {
        SpringApplication.run(SpringBootAdminServerApplication.class, args);
    }
}
```

### 5.2 Security 配置（关键）

```java
package cn.cicoding.admin.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableWebSecurity
public class SecuritySecureConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/assets/**").permitAll()   // 静态资源放行
                .requestMatchers("/login", "/logout").permitAll()  // 登录页放行
                .requestMatchers("/actuator/**").permitAll() // ★ 健康检查放行（否则 SBA 自身显示 DOWN）
                .anyRequest().authenticated()                // 其他需要登录
            )
            .formLogin(Customizer.withDefaults())
            .httpBasic(Customizer.withDefaults())
            .csrf(csrf -> csrf.ignoringRequestMatchers("/actuator/**")); // ★ actuator 关闭 CSRF
        return http.build();
    }
}
```

> ⚠️ **踩坑提示**：如果 `.requestMatchers("/actuator/**").permitAll()` 缺失，SBA 自身在控制台会显示为 **DOWN**。原因是 SBA 通过 HTTP 访问自己的 `/actuator/health` 获取状态，Security 拦截导致 401 → SBA 判定为 DOWN。

### SBA 4.x 与 Spring Security 6+ API 对照

| 旧 API（Spring Security 5） | 新 API（Spring Security 6+） |
|---------------------------|---------------------------|
| `WebSecurityConfigurerAdapter` | `SecurityFilterChain` Bean |
| `.antMatchers()` | `.requestMatchers()` |
| `.and()` | 方法链式调用 |
| `csrf().disable()` | `csrf(csrf -> csrf.disable())` |

## 6. 被监控服务如何配置

确保每个需要被监控的服务有以下配置：

```yaml
# 所有微服务通用配置
management:
  endpoints:
    web:
      exposure:
        include: '*'          # ★ 暴露所有 actuator 端点
  endpoint:
    health:
      show-details: always   # ★ 显示详细健康信息
```

**不需要**在被监控服务中添加 `spring-boot-admin-starter-client` 依赖。SBA 4.x + Nacos 会自动发现服务。

## 常见问题

### Q: SBA 控制台中自己显示 DOWN？

确认 `SecuritySecureConfig` 中放行了 `/actuator/**`：

```java
.requestMatchers("/actuator/**").permitAll()
```

### Q: 其他服务显示 DOWN？

检查：
1. 该服务的 actuator 端点是否正确暴露
2. 该服务是否引入了 Security 但未放行 `/actuator/**`
3. 该服务的 Nacos 注册状态是否正常

### Q: SBA 版本选哪个？

| Spring Boot | SBA 版本 |
|-------------|----------|
| 4.0.x | 4.0.4 ✅ |
| 3.4.x | 3.4.1 |
| 2.7.x | 2.7.x |
