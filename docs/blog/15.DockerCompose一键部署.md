## 1. 整体部署架构

```
Docker Compose 编排
├── nacos (8848/9848)             # 注册 + 配置中心
├── mysql (3306)                   # 数据库
├── consul (8500)                  # 备用注册中心
├── skywalking-oap (11800/12800)   # 链路追踪数据收集
├── skywalking-ui (8080)           # 链路追踪 UI
├── admin-server (8000)            # Spring Boot Admin 监控
├── gateway (7000)                 # API 网关
├── provider (9000)                # 服务提供者
├── provider-file (9001)           # 文件上传提供者
├── consumer-feign (8082)          # Feign 消费者
├── consumer-ribbon (8081)         # RestTemplate 消费者
├── consumer-feign-file (8083)     # 文件上传消费者
├── nacos-config (9003)            # 配置中心示例
├── multiple-config (9004)         # 多配置示例
├── consul-provider (9101)         # Consul 提供者
├── dubbo-provider (9005)          # Dubbo 提供者
└── dubbo-consumer (8084)          # Dubbo 消费者
```

> **注意**：完整部署需要较多内存（建议 16GB+）。开发阶段只需启动核心服务：nacos + mysql + provider + consumer-feign + gateway。

## 2. Dockerfile 编写（以 provider 为例）

在 `spring-cloud-alibaba-provider/` 目录下创建 `Dockerfile`：

```dockerfile
# ========== 多阶段构建 ==========

# 阶段 1: 构建
FROM maven:3.9-eclipse-temurin-17 AS builder
WORKDIR /build

# 先复制父 POM（利用 Docker 缓存层）
COPY pom.xml /build/pom.xml

# 复制模块源码
COPY spring-cloud-alibaba-provider/pom.xml /build/spring-cloud-alibaba-provider/pom.xml
COPY spring-cloud-alibaba-provider/src /build/spring-cloud-alibaba-provider/src

# 构建（只编译当前模块，加快速度）
RUN mvn clean package -pl spring-cloud-alibaba-provider -am -DskipTests

# 阶段 2: 运行
FROM eclipse-temurin:17-jre-alpine AS runtime
WORKDIR /app

# 从构建阶段复制 JAR 包
COPY --from=builder /build/spring-cloud-alibaba-provider/target/*.jar app.jar

# 创建非 root 用户
RUN addgroup --system javauser && adduser --system --no-create-home --ingroup javauser javauser
USER javauser

# 暴露端口
EXPOSE 9000

# 启动
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### Dockerfile 设计要点

| 技巧 | 说明 |
|------|------|
| **多阶段构建** | 构建阶段用 maven 镜像，运行阶段用 jre 镜像，最终镜像不含 Maven 和源码 |
| **分层 COPY** | 先复制 pom.xml 再复制源码，pom.xml 不常变，可复用 Docker 缓存 |
| **-am 参数** | `-am` (also-make) 同时构建依赖的父 POM |
| **非 root 用户** | 安全性最佳实践 |

## 3. 完整的 docker-compose.yml

```yaml
services:
  # ==================== 基础设施 ====================
  nacos:
    image: nacos/nacos-server:v2.5.0
    container_name: nacos-standalone
    restart: unless-stopped
    environment:
      - MODE=standalone
      - NACOS_AUTH_ENABLE=false
      - JVM_XMS=256m
      - JVM_XMX=256m
      - JVM_XMN=128m
    ports:
      - "8848:8848"
      - "9848:9848"
      - "9849:9849"
    volumes:
      - nacos-data:/home/nacos/data
      - nacos-logs:/home/nacos/logs

  mysql:
    image: mysql:8.0
    container_name: mysql-standalone
    restart: unless-stopped
    environment:
      - MYSQL_ROOT_PASSWORD=root
      - MYSQL_DATABASE=mytest
    ports:
      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 10

  consul:
    image: consul:1.15
    container_name: consul-standalone
    restart: unless-stopped
    command: agent -dev -client=0.0.0.0
    ports:
      - "8500:8500"
      - "8600:8600"
    volumes:
      - consul-data:/consul/data

  skywalking-oap:
    image: apache/skywalking-oap-server:10.1.0
    container_name: skywalking-oap
    restart: unless-stopped
    environment:
      - JAVA_OPTS=-Xms512m -Xmx512m
      - SW_STORAGE=h2
    ports:
      - "11800:11800"
      - "12800:12800"
    healthcheck:
      test: ["CMD", "bash", "-c", "cat < /dev/null > /dev/tcp/127.0.0.1/11800"]
      interval: 10s
      timeout: 5s
      retries: 5

  skywalking-ui:
    image: apache/skywalking-ui:10.1.0
    container_name: skywalking-ui
    restart: unless-stopped
    depends_on:
      skywalking-oap:
        condition: service_healthy
    environment:
      - SW_OAP_ADDRESS=http://skywalking-oap:12800
    ports:
      - "8080:8080"

  # ==================== 微服务（核心） ====================
  provider:
    build:
      context: .
      dockerfile: spring-cloud-alibaba-provider/Dockerfile
    container_name: provider
    restart: unless-stopped
    depends_on:
      nacos:
        condition: service_started
      mysql:
        condition: service_healthy
      skywalking-oap:
        condition: service_healthy
    ports:
      - "9000:9000"
    volumes:
      - ./skywalking/agent:/opt/skywalking/agent:ro
    environment:
      # ★ 容器内用服务名访问（非 localhost）
      - SPRING_CLOUD_NACOS_DISCOVERY_SERVER_ADDR=nacos:8848
      - SPRING_DATASOURCE_URL=jdbc:mysql://mysql:3306/mytest?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
      - SPRING_DATASOURCE_USERNAME=root
      - SPRING_DATASOURCE_PASSWORD=root
      # SkyWalking
      - SW_AGENT_NAME=spring-cloud-alibaba-provider
      - SW_AGENT_COLLECTOR_BACKEND_SERVICES=skywalking-oap:11800
      - JAVA_TOOL_OPTIONS=-javaagent:/opt/skywalking/agent/skywalking-agent.jar

  gateway:
    build:
      context: .
      dockerfile: spring-cloud-alibaba-gateway/Dockerfile
    container_name: gateway
    restart: unless-stopped
    depends_on:
      nacos:
        condition: service_started
    ports:
      - "7000:7000"
    volumes:
      - ./skywalking/agent:/opt/skywalking/agent:ro
    environment:
      - SPRING_CLOUD_NACOS_DISCOVERY_SERVER_ADDR=nacos:8848
      - SW_AGENT_NAME=spring-cloud-gateway
      - SW_AGENT_COLLECTOR_BACKEND_SERVICES=skywalking-oap:11800
      - JAVA_TOOL_OPTIONS=-javaagent:/opt/skywalking/agent/skywalking-agent.jar

  admin-server:
    build:
      context: .
      dockerfile: spring-boot-admin-server/Dockerfile
    container_name: admin-server
    restart: unless-stopped
    depends_on:
      nacos:
        condition: service_started
    ports:
      - "8000:8000"
    environment:
      - SPRING_CLOUD_NACOS_DISCOVERY_SERVER_ADDR=nacos:8848

  # ==================== 其他微服务（按需启动） ====================
  consumer-feign:
    build:
      context: .
      dockerfile: spring-cloud-alibaba-consumer-feign/Dockerfile
    depends_on:
      - provider
    ports:
      - "8082:8082"
    volumes:
      - ./skywalking/agent:/opt/skywalking/agent:ro
    environment:
      - SPRING_CLOUD_NACOS_DISCOVERY_SERVER_ADDR=nacos:8848
      - SW_AGENT_NAME=spring-cloud-alibaba-consumer-feign
      - SW_AGENT_COLLECTOR_BACKEND_SERVICES=skywalking-oap:11800
      - JAVA_TOOL_OPTIONS=-javaagent:/opt/skywalking/agent/skywalking-agent.jar

  # consumer-ribbon, provider-file, consumer-feign-file, nacos-config,
  # multiple-config, consul-provider, dubbo-provider, dubbo-consumer
  # ... 其他服务类似配置，按需添加

volumes:
  nacos-data:
  nacos-logs:
  mysql-data:
  consul-data:
```

### 关键配置：容器内地址覆盖

服务在容器内运行时，**不能再用 `localhost`**，必须用 Docker Compose 的服务名：

```yaml
environment:
  # ❌ 错误：容器内 localhost 指向容器自身
  # - SPRING_CLOUD_NACOS_DISCOVERY_SERVER_ADDR=localhost:8848

  # ✅ 正确：用 Docker 服务名
  - SPRING_CLOUD_NACOS_DISCOVERY_SERVER_ADDR=nacos:8848
  - SPRING_DATASOURCE_URL=jdbc:mysql://mysql:3306/mytest?...
```

Docker Compose 的 DNS 会自动将服务名（如 `nacos`）解析为容器 IP。

## 4. 部署操作

### 4.1 构建镜像

```bash
# 构建所有服务的镜像
docker compose build

# 只构建特定服务
docker compose build provider gateway
```

### 4.2 启动集群

```bash
# 启动核心服务
docker compose up -d nacos mysql provider gateway admin-server

# 启动全部服务（内存消耗大）
docker compose up -d

# 查看状态
docker compose ps

# 查看日志
docker compose logs -f provider
```

### 4.3 停止集群

```bash
# 停止所有容器
docker compose stop

# 停止并删除容器
docker compose down

# 停止并删除容器 + 数据卷（清空数据库和配置！）
docker compose down -v
```

### 4.4 健康检查顺序

```
启动顺序：
  nacos → mysql → skywalking-oap
           ↓
  skywalking-ui
           ↓
  provider（依赖 nacos + mysql + skywalking 都就绪）
           ↓
  gateway, admin-server, consumer-feign, ...
```

`depends_on` + `healthcheck` 确保依赖服务就绪后才启动。

## 5. 开发 vs 生产配置差异

| 配置项 | 开发环境 | 生产环境 |
|--------|---------|---------|
| Nacos 认证 | `false` | `true`（必须开启） |
| MySQL 密码 | `root` | 强密码 |
| SkyWalking 存储 | H2（内嵌） | Elasticsearch |
| JVM 内存 | 256m | 512m-2g（按需） |
| 日志级别 | DEBUG | INFO |
| Nacos 模式 | standalone | cluster |
| 健康检查 | 10s | 3s |

建议创建独立的 `docker-compose.prod.yml` 用于生产环境。

## 常见问题

### Q: 容器内服务注册到 Nacos 的地址是容器内部 IP，宿主机无法访问？

这是正常的。服务间通过 Docker DNS（服务名）通信，不需要宿主机访问容器内部 IP。对外暴露的端口通过 `ports` 映射即可。

### Q: 如何只部署核心服务节省资源？

```bash
# 最小部署：只启动必要的
docker compose up -d nacos mysql provider gateway
```

### Q: 构建速度慢怎么办？

1. 使用 `--build-arg` 跳过测试：`MAVEN_OPTS=-DskipTests`
2. 利用 Docker BuildKit 缓存：`DOCKER_BUILDKIT=1 docker compose build`
3. 本地先 `mvn install`，Dockerfile 只做 COPY + 运行
